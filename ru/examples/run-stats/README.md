# Сборщик статистики сессий (opt-in)

Меряйте своего агента, а не гадайте. Claude Code пишет транскрипт каждой
сессии в `~/.claude/projects/` - этот скрипт превращает логи в цифры: сколько
часов агент реально работал, сколько часов вы были рядом и какие строки его
ответов похожи на найденные дефекты.

```bash
python3 collect.py 2026-08-01
```

Вывод по каждой рабочей сессии:

```
===== a1b2c3d4 | 2026-08-02 | агент ~2.8ч | человек ~2.2ч | инструменты: {'playwright': 203}
  первое сообщение: https://tracker/TASK-123 протестируй на стенде
  кандидат: ...активный таб обрезан слева - дефект компонента...
```

## Метод - и его честные границы

- **Часы агента = активное время.** Сумма интервалов между событиями сессии,
  паузы больше 30 минут отрезаются. Wall-clock не использовать никогда:
  сессия, открытая неделю, покажет 170 фейковых часов.
- **Часы человека = присутствие.** Та же математика по вашим сообщениям,
  порог 20 минут. Это нижняя оценка - молчаливое наблюдение в лог не попадает.
- **Дефект-кандидаты - это подсказки, а не счёт.** Скрипт выносит строки на
  чтение; что из этого реальная находка, кто её нашёл и что оказалось ложным -
  решает человек.
- **Транскрипты ротируются** (по умолчанию 30 дней). Архивируйте сырые
  `.jsonl`, если датасет должен пережить ротацию.

## Адаптация

Правьте конфиг-блок в начале файла: добавьте фрагменты имён своих проектных
папок в `WORK_DIRS` (папка проекта - работа по определению: сессии
автоматизации почти не делают MCP-вызовов), песочницы - в `SKIP_DIRS`,
семейства MCP в `WORK_TOOLS` - под свой стек.

Приватность: скрипт только читает локальные файлы и печатает в stdout.
Наружу не уходит ничего.
